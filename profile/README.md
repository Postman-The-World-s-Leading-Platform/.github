# Project Overview

Postman is an API platform designed for developing, testing, documenting, managing, and distributing APIs and services. It provides tools for individual developers as well as teams working across the complete API lifecycle.

The platform includes an API client for sending requests and inspecting responses, workspaces for organizing API projects, collections for reusable requests, environments for configuration management, automated testing, documentation, mock servers, monitoring, and collaboration features.

In 2026, Postman introduced an updated AI-native platform focused on API development and agent-based workflows. The new platform integrates Git-connected workspaces, an API Catalog, Private API Network capabilities, and AI-assisted development features.

---

# API Client & Request Testing

Postman's API client allows developers to create and send requests to HTTP, GraphQL, gRPC, SOAP, and WebSocket services. Responses can be inspected directly inside the application, making it useful for development, debugging, and API testing.

Requests can include parameters, headers, authentication, request bodies, variables, and other configuration required by an API.

Collections allow related requests to be grouped together and reused across development and testing workflows.

Postman can also be used to write tests that validate API responses and automate repeated checks.

---

# Collections, Workspaces & Environments

Collections provide a structured way to organize API requests, tests, documentation, and related resources.

Workspaces provide a shared environment for API projects and can contain collections, specifications, environments, mock servers, and other API assets.

Environments allow developers to store reusable variables such as API endpoints, credentials, identifiers, and configuration values. This makes it possible to switch between development, testing, staging, and production configurations without manually changing every request.

The updated Postman platform also supports Git-connected workflows, allowing API work to be integrated more closely with source-control processes.

---

# API Design, Documentation & Mock Servers

Postman provides tools for working with API specifications and designing APIs before all backend services are available.

Mock servers can simulate API responses, allowing frontend and backend teams to work against predictable endpoints during development.

API documentation can be generated from Postman collections and shared with other developers or API consumers.

The platform can therefore support workflows from initial API design through implementation, testing, documentation, and distribution.

---

# Automation, CLI & Integrations

Postman provides a command-line interface for running collections and integrating API testing into development and CI workflows.

The Postman CLI can execute collections, lint API schemas, perform security and governance checks, and authenticate from local environments or CI systems.

Postman also provides integrations for development environments, including a Visual Studio Code extension that allows users to work with APIs directly from their editor. The extension also supports VSCodium, Cursor, and Windsurf.

---

# AI-Native API Development

Postman's 2026 platform introduces AI-assisted capabilities intended to support API development and maintenance.

Postman AI features can assist with API design, test generation, mock creation, troubleshooting, and other development workflows. Agent Mode is designed to work across API-related tasks while maintaining context from the surrounding project.

The platform also introduces AI-oriented workflows alongside existing collections, specifications, workspaces, tests, and Git-based development processes.

# System Compatibility & Performance

Postman provides native desktop applications for Windows, macOS, and Linux. The current documentation lists Windows 10 or later, macOS 11 or later, and supported Linux distributions including Ubuntu 18.04+, Fedora 32+, and Debian 10+.

| Component        | Minimum Practical Configuration                        |
| ---------------- | ------------------------------------------------------ |
| Operating System | Windows 10 / Windows 11, macOS 11+, or supported Linux |
| Processor        | Modern 64-bit multi-core CPU                           |
| Memory           | 4 GB RAM minimum; 8 GB+ recommended                    |
| Storage          | 1 GB+ for application and local data                   |
| Graphics         | Integrated graphics supported                          |
| Display          | 1280×720 or higher                                     |
| Architecture     | x64 or ARM64 depending on platform                     |
| Internet         | Required for online API services and synchronization   |

Actual resource usage depends on the number of open workspaces, collections, requests, response sizes, mock servers, extensions, and other development tools running simultaneously.

The Postman web application is also available for browser-based API development, while the desktop application provides additional capabilities and deeper integration with local development workflows.
